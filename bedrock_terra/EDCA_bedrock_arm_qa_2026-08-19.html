The baseline sits at 98.33%, leaving roughly 1.7 points of headroom. The primary contrast cannot be meaningfully non-zero, and it measured exactly zero. This is not evidence that DCA fails. It is the instrument failing to discriminate: v0.5.1 was calibrated against a model with a ~74% baseline, and Terra enters at 98%.

One signal survives. M0−B0 = −3.33 pp against Kimi’s −3.7 pp: open-loop memory mildly harms performance in both models. That is a cross-model reproduction of the only contrast Terra can still resolve, and it is consistent with the sealed result.

2. Where the ceiling is not

The aggregate hides the structure. Every one of the ten errors in the 360-call run is the same error, on the same two canonical contexts, in one template family. Four of the five families are perfect in all three conditions.

The failure mode is single and nameable. On TEMPORAL_GAP contexts whose oracle answer is a commitment (CAN51-0017 → TAILOR_SUPPORT, CAN51-0021 → CONTINUE_SUPPORT, both with hidden evidence: COMPLETE), the model instead returns WAIT_FOR_EVIDENCE / R02_EVIDENCE_INCOMPLETE — which is the correct answer for the other contexts in that family. Faced with a temporal gap it falls back to the family’s modal answer rather than resolving the gap. No other error occurs anywhere in the run.

Restricting to the only family with headroom separates the two mechanisms the benchmark conflates:

A dissociation, offered as a hypothesis and nothing more. Terra gains nothing from the resolution DCA performs — it already resolves — but it is still harmed by ungoverned memory, and on the hard family the harm is large and every discordant pair runs the same way (4/0 and 0/4, no reversals). The governance half of the mechanism does not require capability headroom in the way the resolution half does: a model that cannot get more correct can always be made less correct.

The statistics do not support asserting this. Discordant counts of 4/0 give an exact two-sided p = 0.125; two canonical contexts drive every number in the table; the endpoint is non-deterministic, so B1−B0 = 0.00 pp cannot be distinguished from run-to-run noise at this scale. This is a subgroup identified after seeing the results. It is a hypothesis for pre-registration, not a finding.

4. Determinism: a global amendment, not a per-arm one

The frozen configuration specifies temperature: 0 and seed: 13082642. On Terra, temperature: 0 is rejected outright: “Only the default (1) value is supported.” On both arms seed is accepted and silently ignored — three identical calls with a fixed seed produced three different outputs on each model.

Correction to an earlier recommendation. The two-arm design was proposed partly on the grounds that Qwen3 would preserve the frozen determinism clause, leaving any amendment scoped to a single arm. Measurement disproves that. The amendment is global. Cross-model replication still justifies two arms; the reproducible-anchor argument does not survive.

Consequences are narrower than they appear. The causal contrast is unaffected — generation noise is variance, not bias, and the clustered bootstrap already propagates it. What changes is that exact numerical replication becomes impossible, and the estimand shifts from the effect in this system to the expected effect over the model’s output distribution. Both are declarable in one sentence of the protocol annex.

Run-to-run variability was measured directly on Terra (one development memory, 45 calls × 3 executions): byte-identical text 2.2%, identical decision 77.8%, identical scored correctness 100%, accuracy shift 0.00 pp. The variation lives in phrasing and evidence citation, not in the reaction. That figure is currently confounded by the ceiling and must be re-measured if a viable arm is found.

5. Terra cannot be version-pinned

There is no dated variant of openai.gpt-5.6-terra, the response echoes the alias rather than a resolved version, and system_fingerprint is null. Neither the configuration nor the response reveals what actually served the request. If AWS moves the model behind the alias mid-run, the data will not show it.

This is a limitation to declare, not to engineer around. Available mitigations: record the run window so the served version is bounded in time, and rely on an open-weights arm as the reproducible anchor of the pair.

6. Cost and operations

Measured, not estimated. Terra consumes ~1,820 input and ~110 output tokens per call against Kimi’s 1,495-token output mean — roughly thirteen times more output-efficient. A full 1,800-call arm costs approximately US$9 on Terra and under US$3 on Qwen3. Truncation risk at the frozen 4,096 ceiling is effectively nil, against 4.0% measured on the sealed Kimi run.

Cost is not a constraint on this campaign. A client-side hard spend cap is enforced per call by the adapter, since Bedrock has no native spend limit and AWS Budgets lags billing data by hours.

Decisions required

Decision 1 · blocking

Arm selection, given the ceiling

Terra cannot serve the primary endpoint as the benchmark stands. Options: harden the task set so a frontier baseline is not saturated (a redesign, and it breaks comparability with the sealed Kimi result); retain Terra only as a saturation control and run the primary on models with measured headroom; or select arms by measured baseline headroom rather than by capability tier. Qwen3’s development split has since been run and the arm is eligible: 360/360 terminal, every frozen operational monitor at or near its floor, and the full reserved matrix feasible in about 1.6 hours for roughly US$0.59. Eligibility was decided on operational evidence alone, under a code-enforced blind, before any contrast was read.

Section 2 adds a fourth, cheaper option and one hazard. The ceiling is not uniform: difficulty is concentrated in TEMPORAL_GAP, and a frontier arm built around the difficulty structure that survives would not require rebuilding the dataset. The hazard is that this subgroup was identified after seeing results, and selecting the contexts where an effect can appear is the same error as defect D3 in benchmark v3.2. It is admissible only as a separately pre-registered design, declared as such, and never merged with the sealed result.

Decision 2

Determinism amendment

The frozen temperature/seed clause cannot be satisfied on any Bedrock arm. Requesting approval to declare both arms non-deterministic and to restate the estimand accordingly.

Decision 3

reasoning_effort — a new frozen parameter

No Kimi analogue exists. It must be chosen and frozen before the development sweep. Proposed selection criterion: JSON validity and truncation rate only — never B1−B0, which would repeat defect D3 of benchmark v3.2, tuning a parameter toward our own hypothesis.

Decision 4

Multiplicity

Two arms constitute two confirmatory families. Recommended: two independent pre-registered replications, each carrying its own primary claim, requiring no alpha adjustment. Deciding this after seeing results forfeits confirmatory status.

Provenance: all measurements on the DEVELOPMENT split, executed through the frozen api_runner_qa1.py, qa_core.parse_final_answer and core.interpret with no reimplementation. The reserved 1,440-call split remains untouched. The sealed Kimi result (B1−B0 = +9.79 pp, 95% CI [5.00, 14.79]) stands unchanged and is not superseded by this work.
