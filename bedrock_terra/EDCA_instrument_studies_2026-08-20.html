Part I — Where the benchmark still discriminates

1. As models improve, the signal migrates to one family

Terra spends its whole error budget on one template family. That was post hoc, so it went into a pre-registration with a fixed decision rule, hashed before the test sets were opened, and was then tested on KIMI2 and Qwen3 reserved — whose family breakdowns had never been computed. The test is clean because the design is a complete crossing: every family × outcome cell holds exactly 24 contexts, so the outcome-level view already read on Qwen3 carries no information about this one.

In Qwen3 the pattern does not replicate, and the reason is visible in the first table: its five families sit between 26% and 40%, all near chance, so there is no difficulty gradient to detect and memory helps everywhere without discriminating (difference-in-differences +4.95 pp, [−10.42 · 22.14], null).

One principle at three points on the scale

Verified memory pays off in proportion to what the model cannot do unaided. Terra can do almost everything, so the benchmark measures it in one family; KIMI2 can do some things, so the benefit orders itself by difficulty; Qwen3 can do nothing unaided, so memory carries all five. A frontier model does not exhaust this benchmark — it narrows the region where the benchmark discriminates, and the region it narrows towards is predictable in advance. That is a measurement statement, and it is the reply to "the effect only shows up in weak models".

Part II — What the memory actually does

2. Open-loop memory distracts the competent and orients the lost

The same KIMI2 breakdown read on M0 is monotone in the opposite direction. Not pre-registered; reported as observation.

Family (KIMI2)B0 unaidedM0−B0
TEMPORAL_GAP51.04%+12.50
NEW_EXPERIENCE72.92%−3.12
SOURCE_CHANGE78.12%−6.25
ADDITIONAL_OBSERVATION82.29%−7.29
RECURRENCE86.46%−14.58

The better a model handles a family alone, the more an unresolved assumption costs it; where it is lost, the same assumption helps. The negative M0−B0 reported in every model is therefore not a uniform penalty. It is the average of a mechanism that degrades a system that was already working. That is the most concrete form the governance argument has taken so far.

A weaker sign points the same way. Raising Terra's reasoning effort erased its M0 deficit entirely (95.00% → 98.33%, level with B0) while leaving B0 and B1 identical to the last decimal. But that is four contexts out of 120, inside the noise measured in part III, so it is recorded and not claimed.

3. The memory has two routes to the answer, where the design assumes one

B1 supplies the prospective assumption, the resolved relation, and a comparison guide. Since the marker relation-alpha…epsilon is permuted per memory, the guide is the only thing that translates it, so removing the guide should have destroyed the effect.

Condition (Qwen3, development, 120 contexts)Accuracyvs B0Effect retained
B0 — no memory32.50%——

B1 — full memory50.83%+18.33100%

Each component alone delivers most of the effect: they are substitutable, not complementary. The model reaches the answer either by translating the marker or by reading the resolved relation in prose. The marker itself is cited in 90–98% of replies in every condition including B0, so citation does not reveal which route was used.

A construct question, not a threat to the result

Memory still produces the effect and the confirmatory claim is untouched. What changes is the account of why — the design treats marker translation as necessary and it is not. Better decided now than found by a reviewer.

Power limit: on 120 contexts with a run-to-run sd near 3 pp, the three B1 variants (50.83 / 47.50 / 54.17) all sit inside the spread measured between identical runs, so they cannot be ordered against each other. What is solid is that neither ablation destroys the effect: the gap between the predicted ~0 and the observed +15 is five times the noise.

Part III — How much the numbers can be trusted

5. The effort parameter does nothing, and finding that out gave us the variance

Qwen3 answers ESCALATE_REVIEW for 89% of B0 items. The worry was that we caused it by freezing effort: low. We did not — but the control run is what settled it:

Qwen3 development, same 120 contextsB0M0B1B1−B0ESCALATE in B0
low — frozen config32.50%25.83%50.83%+18.3384.2%
medium32.50%24.17%56.67%+24.1787.5%
low — repeated, config untouched34.17%30.83%56.67%+22.5085.0%

Two runs with the identical parameter separate as much as medium did, and the repeat lands on exactly the same B1 as medium. With reasoning_tokens at zero and output length and latency unchanged, the endpoint accepts the parameter and ignores it, as it does with seed. So the collapse is a property of the model, not of our configuration — and those three runs are three replicates, which is how we obtained a variance estimate we did not have.

The finding we did not go looking for

Ask the same model the same clinical question twice and it changes its decision on 11% of calls — 15% under verified memory, the condition the system would actually deploy. The aggregate is reproducible because the changes cancel almost exactly: in B1, 22 flips improve and 22 worsen. Population-level performance replicates; the individual recommendation does not.

For a decision-support system this is a safety property, not a statistical footnote, and the paper currently does not mention it. It also sharpens the governance argument: a verified memory raises the average and does not deliver determinism. Our suggestion is that this deserves its own paragraph in the limitations, and possibly its own figure.

Run-to-run variability at reserved scale turned out smaller than extrapolation from development predicted, which is good news for the primary: it survives the sensitivity, the repeat and the propagation with a lower bound more than twenty points clear of zero.

Three signs of fragility in M0−B0, none in the primary

First, the repeat run alone gives [−5.42 · 0.00] and does not exclude zero. Second, on Terra reserved the same contrast does not survive the valid-only sensitivity ([−2.51 · +0.21]). Third, the propagated margin is 0.39 pp — and the variance estimate behind it rests on two runs, which is one degree of freedom.

The pre-registered rule demotes M0−B0 only if the propagated interval crosses zero, and it does not. The rule is satisfied, so we have not demoted it unilaterally. We recommend that you do: the direction is now consistent across seven measurements in three model families, which is a real finding, whereas the interval rests on a third of a percentage point.

What none of this establishes, and one operational note

No endpoint, no claim, no change to the confirmatory result. The family analysis is descriptive and your subgroup prohibition stands. The ablation and effort studies are on development data. The repeat run creates no second result and is barred by its own pre-registration from revising any published number in either direction. Every signature today is delegated, recorded as delegated, never under your name.

Operational note for the annex: reasoning_effort: high is unusable on the Qwen3 endpoint. A one-word prompt returns in 0.7 s at low and medium and times out unanswered at high — no error, no response. Terra honours the parameter normally (reasoning tokens 24.7 → 55.4) and its ceiling does not move when it does.
