Auditability Without an Oracle

Renxi's revised question: how does an LLM localise its own error without an oracle — and if it cannot, it is not auditable. It can, partially, with perfect precision and bounded recall. That recall is measurable, it is a property of the model under a memory interface, and cognitive memory doubles it.

Data reserved splits, Terra + Qwen3, 1,440 calls each, 32 memory groups Oracle used only to score the detector, under signed inspection records Status exploratory, post hoc

A consistent error is indistinguishable from consistent correct reasoning. An inconsistent error is a certified error. So the share of a model's errors that are inconsistent is exactly the share it can localise without an oracle — and that share is what auditable should mean for an LLM.

The detector

Each canonical context has one correct rule. The benchmark delivers it in three renderings that differ only in wording. Nothing else is needed.

1 · invariantSame context, three wordingsStructured, chronological and concise renderings of identical evidence. One correct rule exists for all three.
2 · testDo the three returned rules agree?If they differ, at least one is wrong. Certified by logic. The oracle is not consulted.
3 · localiseThe error is in premise selectionRule → reaction is a tautology the models violate once in 2,869 responses. So a disagreement sits upstream, in which evidence was read as which world-state.

Precision is 100% by construction, and it is 100% in every cell below. What varies is recall: the fraction of contexts containing an error that the detector flags. The oracle enters only to count that denominator.

The recall is not a constant of the model. Qwen3 alone can see 30% of its errors; with the pre-specified map it sees fewer, 16%; with cognitive memory it sees 60%. Invisible errors fall from 107 to 87 to 37 along the same gradient. The interface changes how many of the model's mistakes are self-detectable — which is the operational meaning of auditability.

Correction

This reverses the reading I gave earlier today. The aggregate drop in Qwen3's citation stability under cognitive memory (53% → 33%, −20 pp, Holm p = 0.009) is real, and I reported it as "cognitive memory destabilises the model's stated grounds." The decomposition shows the opposite meaning: stability moved from wrong answers to right ones. The aggregate fell because the errors got noisier — which is the detector working. This could only be seen with the oracle, which is itself Renxi's point about baselines.

What this says about the question

Is the LLM auditable? Not in the sense the theory defines — a realised trace compared against a frozen reference certificate. There is no κ* for an LLM's rationale, because the rationale is produced by the same opaque process as the answer, at the same moment, with no prior commitment to compare against. Cognitive memory has that commitment by construction. That is the paper's thesis, not a problem for it.

Can it localise its own error without an oracle? Yes, partially and asymmetrically. Inconsistent errors: certified, localised to premise selection, 100% precision. Consistent errors: invisible, and indistinguishable from correct reasoning. The rationale is falsifiable but not certifiable.

So what is auditability, for an LLM? The recall of this detector — the share of the model's errors that are inconsistent rather than stable. It is a number. Terra is 73–100% auditable in this sense. Qwen3 alone is 30%. Qwen3 under cognitive memory is 60%.

The LLM is not auditable. The LLM under cognitive memory is more auditable than the LLM alone — and that is a cleaner statement of the thesis than the accuracy result.
